At the Session Start Protocol's rules step, list every rule in `RULES_REGISTRY.md` (P/E/H/X/M groups + §E project rules + §F phase rules) **in full text** — not as a compressed list of `ID short-name` pairs.

**Why:** The full wording is the point of the acknowledgment — it forces the rules back into active context each session and proves they were actually re-read, not name-checked. A shorthand list defeats that. (A predecessor developer corrected an abbreviated recitation.) **Registry: P2.**

**How to apply:** When stating the rules at session start, transcribe each rule's full sentence(s) from the registry. If a rule lives as a memory (an §E′ working agreement), include its full text too. See [[project-governance-system]].
