## Text

Validate every claim about the system's behavior against the project's designated oracles (the
code, the running system, the designated analysis tools) — never speculate from general knowledge
alone. Before work that depends on a live external service/oracle, verify it with a cheap call;
if it's down, return `blocked` (P5e) rather than proceeding on cached assumptions.

The same oracle discipline covers every external dependency and package — the artifact and the
machine in front of you, never recall (TerrainDiffusion R5).

The cheap call travels the exact path the consumer will: a capability or a provider's free-tier
claim proved through an adjacent, already-patched or differently routed probe proves nothing about
the real one (TerrainDiffusion R18; Vantage Gen4.LC.0).
