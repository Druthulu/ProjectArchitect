## Text

Before the phase closes the closer runs `phaseend_index.py verify`, which executes every
`verified by` clause of the milestone. Walk the wiring steps that a clause never covers —
registrations, config bindings, gitignore entries, doc updates, integration tasks — and record a
miss as a deviation.
