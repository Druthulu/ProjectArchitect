## Text

`PROJECT_CONTEXT.md` is never edited, rewritten, or appended to after generation. Current state
lives in `phase-ends/current/` (the live plan, task summaries, logs) and the archived
`PhaseEnd_Phase<N>.md` files; rule evolution lives in `rules/`. If the constitution is found to be
wrong, record the correction in the task summary (`tasks/T<n>.md`) so it surfaces in the
PhaseEnd — never in the constitution itself.
