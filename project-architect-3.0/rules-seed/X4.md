## Text

Consult before, capture after, by index, never by reading a corpus.

Before a unit of recurring work: grep `cookbook/INDEX.md` for the tags the task names. The plan's
`## Cookbook` section already names the entries it expects; reading an entry that is neither named
there nor a hit from your own grep is context spent for nothing, and no agent ever reads the
cookbook whole.

After a hard-won win: `bash tools/cookbook_add.sh --title ... --tags ... --file ...` writes
`cookbook/C<nnnn>.md` and its index line. Mark the same finding `generalizable:` in the task
summary so the closer can confirm it landed.

Do not over-encode one-offs: the target is the average case plus a shrinking hard tail. Techniques
belong in the cookbook; norms of conduct are rules (P10); repeatable procedures are skills.
